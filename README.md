# Deutsch Quest B2

## نصب در GitHub Pages
1. فایل ZIP را روی گوشی/کامپیوتر باز و Extract کن.
2. همه فایل‌ها و پوشه‌های داخل `Deutsch_Quest_B2` را در ریشه مخزن `deutsch-quest` آپلود کن؛ فایل‌های هم‌نام قبلی را جایگزین کن.
3. در GitHub وارد **Settings → Pages** شو.
4. در بخش Build and deployment، گزینه **Deploy from a branch**، شاخه `main` و پوشه `/ (root)` را انتخاب کن و Save بزن.
5. پس از چند دقیقه آدرس Pages مخزن را باز کن. برای اولین بار اتصال اینترنت لازم است.

## اضافه کردن درس بعدی
یک فایل مثل `data/lessons/lesson-02.json` بساز و ساختار درس اول را کپی کن. سپس در `data/lessons.json` یک شیء تازه به آرایه `lessons` اضافه کن که `id` و `file` و `title` و `description` و `label` داشته باشد. برای تازه‌شدن نسخه آفلاین، مقدار CACHE در `sw.js` را از `v1` به `v2` تغییر بده.

## امکانات فعلی
- کارت واژگان آلمانی با معنی فارسی، ساختار، مثال و ترجمه
- پخش تلفظ با صدای آلمانی مرورگر
- آزمون چهارگزینه‌ای، XP و ثبت کلمات یادگرفته‌شده
- ذخیره محلی پیشرفت و خروجی پشتیبان
- طراحی واکنش‌گرا و پایه PWA

پیشرفت در مرورگر همین دستگاه ذخیره می‌شود و خودکار بین دستگاه‌ها همگام نمی‌شود. تلفظ به پشتیبانی مرورگر/دستگاه وابسته است.
